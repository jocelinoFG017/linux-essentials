# Curiosidades

1. Ranking das distribuições Linux mais utilizadas:
[Ranking](https://distrowatch.com/)

2. As distribuições do Ubuntu usam datas como números de versão, no formato
`AA.MM`. Por exemplo, a versão 19.04 foi lançada em abril de 2019.

3. Se o valor de uma permissão for ímpar, certamente o arquivo é executável.
